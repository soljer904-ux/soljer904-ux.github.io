Make a heart light up on the micro:bit. ❤️

Open MakeCode here: makecode.microbit.org
On a MacBook, plug the USB cable into the micro:bit and the computer. On an iPad you do not use a cable — use the free micro:bit app and Bluetooth (see tip at the bottom of this mission).
Start a new project

In MakeCode, tap New Project. Call it Heart.

Show a heart

From the blue Basic menu, drag show icon into on start. Choose the heart ❤️.

Download to the micro:bit

MacBook (easiest): plug in USB → tap Download. In Chrome/Edge it can send straight over. In Safari, drag the file onto the MICROBIT drive.

iPad: use the free micro:bit app from the App Store. Write code in the app (or open a project from Chrome/Edge into the app). Put the micro:bit in Bluetooth mode (press the back reset button 3 times until you see the Bluetooth logo), then send. An iPad cannot use a USB cable for this.

Build the beak

Two cardboard triangles that open and shut. 🐤

Help with scissors or a craft knife for the triangles. A cool-melt glue gun needs an adult nearby.
Scissors and craft knives are sharp. Glue guns can still feel hot — ask Dad.
Cut two triangles

About the size of your thumb. One for the top beak, one for the bottom.

Join them with a paper fastener

Push the fastener through both triangles near the thick end so they can open like a mouth.

Add a rubber band

Loop a rubber band so the beak wants to stay shut.

Tape Servo 1 under the lower beak

When the servo horn pushes up, the beak opens. Keep the lever short (about 5 cm). Label this servo BEAK with a sticker or tape.

Code: open on A, close on B

on button A pressed → set servo 1 angle to 40

on button B pressed → set servo 1 angle to 90

Try different numbers until the beak looks right. Don't go past where it feels stuck.

🎉 You did it! The parrot can chat!

Build the wings

Two little levers that flap together. 🪽

One servo moves both wings. Keep each wing lever about 5 cm long so the little motor is strong enough.
Cut two wing shapes

Cardboard wings, about the length of your hand. Tape a lolly stick to each for strength.

Mount Servo 2 in the middle

Plug it into Servo 2 on the board. Tape a cross-shaped horn so both wings can sit on opposite sides and flap together. Label it WINGS.

Help hold the body while taping. Elastic bands through the board's side holes can hold the electronics in place later.
Code a flap loop

on button A pressed

Inside, from green Loops: repeat 4 times

Inside the repeat:

set servo 2 angle to 60

pause (ms) 300

set servo 2 angle to 120

pause (ms) 300

Download and flap!

Press A and watch the wings go. Change 60 and 120 if you need a bigger or smaller flap.

For Dad — wiring, pins & full code

Hardware from the project pack (Pi Hut order arrived). Kitronik Simple Servo Control Board + 3× TowerPro SG90 (180°) + micro:bit V2 Go.

Wiring / pin table

PartBoard socketMakeCodemicro:bit pinWire colours
BeakServo 1servo 1P8G←brown, V←red, S←orange
WingsServo 2servo 2P15same
TailServo 3servo 3P16same

micro:bit slots into the edge connector (LEDs facing you). Board powered by 3×AA; power switch on the board. Croc pads break out P0, P1, P2, Switch A (P5), 3V, GND — not needed for the parrot.

Extension: MakeCode → Extensions → search “Simple Servo” (KitronikLtd/pxt-kitronik-simple-servo). Blocks are purple under Servo.

Download: Mac vs iPad

  • MacBook: USB cable to micro:bit. Chrome/Edge can WebUSB-download directly. Safari downloads a .hex — drag onto the MICROBIT drive.
  • iPad: Apple blocks USB program transfer. Install the free micro:bit iOS app. Code inside the app (or hand off from Chrome/Edge into the app). Send over Bluetooth: press reset 3 times for the Bluetooth logo, then transfer. Safari alone cannot flash the board.

Suggested full MakeCode (blocks → JavaScript view)

// Add extension: Simple Servo (Kitronik)
// Angles are starting points — tweak for your cardboard.

input.onButtonPressed(Button.A, function () {
    // Talk + flap
    kitronik_simple_servo.setServoAngle(
        kitronik_simple_servo.ServoChoice.servo1, 40)
    for (let i = 0; i < 2; i++) {
        kitronik_simple_servo.setServoAngle(
            kitronik_simple_servo.ServoChoice.servo2, 60)
        basic.pause(300)
        kitronik_simple_servo.setServoAngle(
            kitronik_simple_servo.ServoChoice.servo2, 120)
        basic.pause(300)
    }
    kitronik_simple_servo.setServoAngle(
        kitronik_simple_servo.ServoChoice.servo1, 90)
})

input.onButtonPressed(Button.B, function () {
    // Wag tail
    for (let i = 0; i < 6; i++) {
        kitronik_simple_servo.setServoAngle(
            kitronik_simple_servo.ServoChoice.servo3, 70)
        basic.pause(200)
        kitronik_simple_servo.setServoAngle(
            kitronik_simple_servo.ServoChoice.servo3, 110)
        basic.pause(200)
    }
    kitronik_simple_servo.setServoNeutral(
        kitronik_simple_servo.ServoChoice.servo3)
})

input.onLoudSound(function () {
    // Clap party
    kitronik_simple_servo.setServoAngle(
        kitronik_simple_servo.ServoChoice.servo1, 40)
    kitronik_simple_servo.setServoAngle(
        kitronik_simple_servo.ServoChoice.servo2, 60)
    kitronik_simple_servo.setServoAngle(
        kitronik_simple_servo.ServoChoice.servo3, 70)
    basic.pause(400)
    kitronik_simple_servo.setServoNeutral(
        kitronik_simple_servo.ServoChoice.servo1)
    kitronik_simple_servo.setServoNeutral(
        kitronik_simple_servo.ServoChoice.servo2)
    kitronik_simple_servo.setServoNeutral(
        kitronik_simple_servo.ServoChoice.servo3)
})

basic.forever(function () {})

kitronik_simple_servo.setServoNeutral(
    kitronik_simple_servo.ServoChoice.servo1)
kitronik_simple_servo.setServoNeutral(
    kitronik_simple_servo.ServoChoice.servo2)
kitronik_simple_servo.setServoNeutral(
    kitronik_simple_servo.ServoChoice.servo3)
basic.showIcon(IconNames.Heart)
